# MPLAD-Guard Data

This folder contains the datasets used by the MPLAD-Guard Project Monitoring and Risk Analysis System.

## Structure

```text
data/
├── raw/
├── processed/
├── external/
└── README.md
```

## Data Folders

### Raw

Contains original project monitoring datasets before processing.

### Processed

Contains cleaned and transformed datasets prepared for analysis and machine learning.

### External

Contains external datasets that may be used to improve project monitoring, risk analysis, and prediction.

## Usage

The data in this folder can be used by the machine learning components for preprocessing, training, evaluation, and prediction.
