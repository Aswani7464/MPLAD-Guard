# MPLAD-Guard

MPLAD-Guard is a Project Monitoring and Risk Analysis System designed to support monitoring, risk assessment, verification, analytics, and reporting of development projects.

## Project Overview

The system combines:

- React Web Application
- FastAPI Backend
- Supabase Database
- Machine Learning
- Artificial Intelligence
- Project Risk Analysis
- Project Verification
- Analytics and Reports
